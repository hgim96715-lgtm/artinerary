# Artinerary

공공 문화 API와 관리자 등록 데이터를 통합해, 사용자가 전시를 탐색하고 찜하거나 관람 기록을 남길 수 있는 **전시 큐레이션 서비스**입니다.

---

## 목표

- 공공 문화 데이터를 자동 수집·정규화해 일관된 전시 카탈로그를 구축한다.
- 관리자가 직접 전시를 등록·수정·숨김 처리할 수 있다.
- 사용자는 전시를 검색·탐색하고, 찜과 관람 기록을 남길 수 있다.
- 수집 → 저장 → API → 화면 → 배포까지 한 흐름으로 운영 가능한 구조를 만든다

---

## 시스템 아키텍처

```
[외부 문화 API]
        ↓
[NestJS Collector Service]     ← 주기적/수동 수집
        ↓
[데이터 정규화 / 중복 체크]
        ↓
[PostgreSQL Exhibition 저장]
        ↓
[NestJS Exhibition API]        ← 사용자·관리자 공통 백엔드
        ↓
[Next.js 사용자 화면]

[관리자 페이지]
        ↓
[직접 전시 등록 / 수정 / 숨김 처리]
        ↓
[PostgreSQL Exhibition 저장]
```
